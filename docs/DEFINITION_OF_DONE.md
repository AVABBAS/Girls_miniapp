# Definition of Done

A feature is done when:
- acceptance criteria are implemented;
- type checks pass;
- lint/format checks pass;
- relevant tests pass;
- build passes when applicable;
- mobile/Telegram WebView behavior is considered;
- authorization and input validation are covered;
- no secrets are committed;
- docs/config examples are updated when needed;
- git status is clean except for intentional changes;
- the change is committed with a meaningful message.

A milestone is done when every task in that milestone is complete and a smoke test covers the integrated flow.
